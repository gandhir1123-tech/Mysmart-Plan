# MySmart Plan 📱💰

**MySmart Plan** is a mobile-first personal finance and daily maintenance accounting web app featuring a modern Glossy Blue Wallet design, clean dual-account tracking, split-bill group management, and 5 power UI/UX enhancements.

## 🌟 Key Features

* **Brand Identity & Glossy Blue Wallet Logo**:
  * Vibrant Glossy Royal Blue & Cyan Wallet app icon.
  * Crisp high-resolution PWA icons (`icon-512.png`, `icon-192.png`, `favicon.png`, `logo.png`).
* **Topic 1 — Floating Action Button (FAB `+`) & Quick Logger**:
  * Persistent central floating `+` button on the bottom navigation bar.
  * Instant bottom-sheet logger accessible from any tab (Home, Expenses, Categories) with 1-tap quick logging.
* **Topic 2 — Smart Merchant Memory & Quick Math Calculator**:
  * Predictive chips based on past habits auto-fill description, category, and payment mode as you type.
  * Instant math evaluation directly inside amount fields (e.g. typing `120+45+30` evaluates to `₹195`).
* **Topic 3 — Safe Daily Spend Allowance & Compact List Toggle**:
  * Dynamic daily pacing indicator (*"Safe to spend: ₹X/day remaining for N days"*) on Home Dashboard.
  * Single-tap density switcher (`≡ Compact` vs `⊞ Detailed`) to fit 10+ transactions on phone screens.
* **Topic 4 — Aggregated Friends Summary ("Who Owes Me What")**:
  * Consolidated group balance sheet grouping pending splits by friend.
  * 1-Tap Combined WhatsApp Reminders and 1-Tap "Settle All" per person.
* **Topic 5 — True AMOLED Dark Mode Theme (`☀️ / 🌙`)**:
  * Pure obsidian dark theme (`#07090e`) saving battery life on OLED screens with smooth persistence.
* **Split Bill & Group Expense Calculator (👥 Split Bill)**:
  * Auto-calculates per-person shares with individual friend cards and day-by-day settlement.
* **80% & 100% Category Budget Warning Alerts (🚨 / ⚠️)**:
  * Real-time warning banners on Home and category health indicators.
* **Strict Two-Account Separation**:
  * Regular Expense vs Personal Account with bidirectional `⇄ Transfer`.
* **Print-Ready PDF Monthly Statement**:
  * Clean A4 print layout with KPI cards, itemized group splits table, and category breakdown.
* **100% Offline & Private**:
  * Zero servers, 100% local device storage in `localStorage` with JSON backup & restore.

## 🚀 Getting Started

1. Download or clone this repository.
2. Open `index.html` in any modern web browser on your phone, tablet, or desktop.
3. Add to Home Screen (PWA) for a native app experience.
