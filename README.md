# MySmart Plan - Personal Finance & Expense Tracker

A modern, responsive, mobile-first personal accounting and expense planning web application. Designed for individual and private use with zero server tracking and persistent offline storage.

## Features
- **Individual & Private Use**: Financial data is stored 100% locally on each user's device (`localStorage`).
- **PWA Ready**: Works offline and can be added directly to mobile home screens.
- **Multi-Account & Transfer Support**: Manage personal accounts, daily expenses, and transfers cleanly.
- **Recurring Bills & Auto-Calculations**: Dynamic budgeting, spending equations, and ledger views.
- **Backup & Restore**: Export and import your data anytime via JSON.
